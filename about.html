About FindBack

A frontend-only Lost and Found Management System.

Project Purpose

FindBack helps campus users report lost and found items, browse reports, search and filter items, view full details, connect a Lost report with a related Found report, and track whether an item is still missing, matched, claimed or returned.

Technology

HTML is used for page structure, CSS for responsive design and JavaScript for validation, dynamic content, search/filter, editing, status updates and browser localStorage.

Project Workflow

The main functional flow of the system.

1

Submit

Report an item as Lost or Found.

2

Browse

Search and filter submitted reports.

3

Match

Connect a similar Lost report with a Found report.

4

Return

Confirm recovery and mark both connected reports Returned.

Status Flow

Lost report: Lost → Match with a Found report → Matched → Returned

Found report: Found → Match with a Lost report → Claimed → Returned

When the user confirms a pair, both reports are linked by report ID. When the item is returned, one action updates both reports to Returned.
